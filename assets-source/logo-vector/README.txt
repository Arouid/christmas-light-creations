Christmas Light Creations - cottage logo, vector files (SVG)
Traced from the 2012 site's winter backdrop (the same cutout the website uses), 2026-10-10.

Cottage only
  clc-cottage-color.svg                 full color with the neon glow, transparent background (use on dark)
  clc-cottage-color-on-navy-tile.svg    same, inside a rounded navy square (app icon / profile picture)
  clc-cottage-one-color-white.svg       one color, white: shirts, dark vinyl, truck doors on dark paint
  clc-cottage-one-color-navy.svg        one color, navy, solid roof: stamps, embroidery, small prints
  clc-cottage-one-color-navy-outline.svg  one color, navy, roof and snow drawn as outlines: letterhead, light vinyl

With the name (lettering converted to outlines, no fonts needed)
  clc-logo-stacked-*.svg                cottage above "Christmas Light Creations" + "Pearland, TX - Since 2011": yard signs, shirts

  (each in color, one-color-white and one-color-navy)

Notes
- Scales to any size without blur. Opens in Illustrator, Inkscape, Affinity, Canva, any browser.
- The glow in the color files is an SVG blur filter. For a vinyl cutter, embroidery or a one-color print use the one-color files; they have no filter.
- One color means exactly that: give the shop the white file for dark material or the navy file for light material; they can recolor it to any single ink.
- Colors used: navy #050b1a / #06132c, magenta #f038ee, green #5fe757, red glow #ff3a3a, window purple #c92ecf, gold #ffcf4d.
- Rebuild: logo-vector.local/ (gitignored) has the tracing scripts; PNG exports: node logo-vector.local/render.mjs <svg> <out.png> <width> [bg].
